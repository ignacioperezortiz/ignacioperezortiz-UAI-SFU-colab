## Conventions

- Records are grouped by the meeting date using `YYYY-MM-DD`.
- Filenames use lowercase kebab-case for predictable links.
- For paired files, the PDF is the review-ready snapshot and the DOCX is the
  editable source.
- These files are formal collaboration records. Personal notes, local runbooks,
  transcripts, and machine-specific working logs remain outside the repository.
